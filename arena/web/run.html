Run detail运行详情

One published run bundle. The trace shows what it did; the claim verdicts show what it was and was not allowed to say. A refusal with a code is an outcome, not a missing value. 一个已发布的运行包。轨迹显示了它做了什么；主张裁定显示了它被允许说什么、不被允许说什么。带代码的拒绝是一种结果，不是一个缺失的值。

Addressed as run.html?id=<run_id>寻址方式 run.html?id=<run_id>

TCMScience Arena. A read-only evaluation surface. It renders published result bundles; it never computes a score, never re-ranks, and never writes a registry. 只读评测平台。它渲染已发布的结果包；从不计算分数、从不重新排名、也从不向任何注册表写入。

Static HTML, one stylesheet, one script. No server, no database, no cookies, no tracking.纯静态 HTML，一个样式表、一个脚本。无服务器、无数据库、无 Cookie、无追踪。
