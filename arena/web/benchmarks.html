Benchmark registry基准注册表

A Season is the unit of comparability. It is cut from a Stable Registry revision and is thereafter immutable: a monthly skill update can never modify it, because otherwise this month's score and last month's are not on the same scale. 赛季（Season）是比较性的单位。它从某个稳定注册表（Stable Registry）修订版中切出，此后不可更改：月度技能更新永远不能改动它，否则本月与上月的分数就不在同一把尺子上。

Frozen registry冻结注册表 Append-only只追加

Seasons赛季

Each Season names its version, the date it was frozen, its case count and its splits. The case files themselves are not published here. 每个赛季写明自己的版本、冻结日期、题目数量与划分。题目文件本身不在这里发布。

Why the cases are not on this page为什么题目不在本页

A public gold answer contaminates the benchmark for everyone who clones it. The schema, the loader, the scorers and the data card are published; the cases and their gold labels are withheld so a clone cannot be prompted or trained against them. A new system iterates against the public development split and is scored, once, on the held-out one. 公开的黄金答案，会污染每一个克隆它的人手中的基准。schema、加载器、评分器与数据卡是发布的；题目及其黄金标签被隐去，这样克隆者就无法针对它们做提示或训练。新系统对着公开的开发集迭代，只在留出集上被评分一次。

Tracks in the current Season当季赛道

Six tracks, twenty cases each. Each track has its own scorer and its own metric focus — the dimensions are shared across tracks, what varies is what each one is measuring. 六条赛道，每条二十道题。每条赛道有自己的评分器和自己的指标重心——维度在各赛道之间共用，变化的是每一项在测量什么。

Data sources and licences数据源与许可

External databases change without telling us. A source is pinned by content, not by a date: the snapshot hash is what a downstream artifact cites, because “version 2.0” is not a version and a hash is. 外部数据库不会通知我们就改变。来源是按内容钉住的，不是按日期：下游 artifact 引用的是快照哈希（snapshot hash），因为「2.0 版」不是一个版本，而哈希是。

A licence string is not evidence that a licence permits this use. Each source carries a licence_verified flag set by a human reviewer at Season cut; the flag is rendered next to the string rather than assumed from it. An artifact resting on a source with no identified licence fails validation (ART103). 一个许可字符串，不等于该许可允许这种用法。每个来源带一个 licence_verified 标记，由人类审阅者在赛季切出时设置；该标记与字符串并排渲染，而不是由字符串假定而来。一个建立在未标明许可的来源之上的 artifact，验证不通过（ART103）。

Scoring rules评分规则

The rules below are the ones that apply to every track. Track-specific scorers are described with the track. 下列规则适用于每一条赛道。赛道专属的评分器随赛道一同说明。

Hard gates硬门槛

Applied before ranking, never as a score contribution. A gated run appears on the Experimental board with its blocking reason. 在排名之前施加，绝不作为分数贡献。被门槛拦下的运行，会连同拦截原因出现在实验榜上。

How to cite如何引用

Cite the Season and the four version axes, not the website. The axes are what make the number re-derivable by someone who has none of your code. 引用赛季与四条版本轴，而不是引用这个网站。正是这四条轴，让一个手里没有你任何代码的人也能重新推导出这个数字。

Replace the example identifiers with the ones printed on the run page of the result you are citing. A result whose four axes are not all resolvable in the published registries is not rendered on the leaderboard at all. 把示例标识符替换成你所引用结果的运行页上印出的那些。一个四条轴不能全部在已发布注册表中解析出来的结果，根本不会在排行榜上渲染。

TCMScience Arena. A read-only evaluation surface. It renders published result bundles; it never computes a score, never re-ranks, and never writes a registry. 只读评测平台。它渲染已发布的结果包；从不计算分数、从不重新排名、也从不向任何注册表写入。

Static HTML, one stylesheet, one script. No server, no database, no cookies, no tracking.纯静态 HTML，一个样式表、一个脚本。无服务器、无数据库、无 Cookie、无追踪。
