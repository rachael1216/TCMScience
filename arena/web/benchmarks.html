Benchmark registry基准注册表

A Season is the unit of comparability. It is cut from a Stable Registry revision and is thereafter immutable: a monthly skill update can never modify it, because otherwise this month's score and last month's are not on the same scale.

Frozen registry Append-only

Seasons

Each Season names its version, the date it was frozen, its case count and its splits. The case files themselves are not published here.

Why the cases are not on this page

A public gold answer contaminates the benchmark for everyone who clones it. The schema, the loader, the scorers and the data card are published; the cases and their gold labels are withheld so a clone cannot be prompted or trained against them. A new system iterates against the public development split and is scored, once, on the held-out one.

Data sources and licences

External databases change without telling us. A source is pinned by content, not by a date: the snapshot hash is what a downstream artifact cites, because “version 2.0” is not a version and a hash is.

A licence string is not evidence that a licence permits this use. Each source carries a licence_verified flag set by a human reviewer at Season cut; the flag is rendered next to the string rather than assumed from it. An artifact resting on a source with no identified licence fails validation (ART103).

Scoring rules

The rules below are the ones that apply to every track. Track-specific scorers are described with the track.

Hard gates

Applied before ranking, never as a score contribution. A gated run appears on the Experimental board with its blocking reason.

How to cite

Cite the Season and the four version axes, not the website. The axes are what make the number re-derivable by someone who has none of your code.

Replace the example identifiers with the ones printed on the run page of the result you are citing. A result whose four axes are not all resolvable in the published registries is not rendered on the leaderboard at all.

TCMScience Arena. A read-only evaluation surface. It renders published result bundles; it never computes a score, never re-ranks, and never writes a registry.

Static HTML, one stylesheet, one script. No server, no database, no cookies, no tracking.
