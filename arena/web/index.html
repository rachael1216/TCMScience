The TCMScience ArenaTCMScience 评测平台

A public scoreboard for AI systems that answer Traditional Chinese Medicine research questions. Six task types. Eight scores per system, always shown separately. Four hard rules that are displayed, not hidden.

六类任务，每个系统八项分数（永远分开显示），四条硬性规则（明示而非隐藏）。

How to read this site怎么看这个网站

  1. Start with the leaderboard. Each row is one system on one task type. The score is broken into eight parts; all eight are always visible.
  2. Click any row to see exactly what that system did — what it looked up, what it produced, and which claims it refused to make.
  3. Check the "Board" label. Trusted means the system passed all four hard rules. Experimental means it did not, and the reason is printed next to it.
  4. Numbers are never edited by this site. It only displays what the evaluation produced.
  1. 先看「排行榜」。每一行 = 一个系统在某类任务上的成绩。分数拆成 八项，八项永远同时显示。
  2. 点任意一行，能看到这个系统具体做了什么——查了什么、产出了什么、 以及它拒绝做出哪些结论。
  3. 注意「榜单」标签。可信榜＝四条硬规则全部通过； 实验榜＝未通过，旁边会写明原因。
  4. 本站不改动任何数字。它只显示评测产出的结果。

What the Arena is这个平台是什么

The Arena is the publishing half of TCMScience. Evaluation happens elsewhere — in the Runner, under a frozen policy snapshot — and writes signed result bundles into the Frozen Benchmark Registry. This site renders those bundles.

That division is the whole design. It exists so that a leaderboard number cannot be edited by the website that displays it, and so that compromising the website does not compromise a result. Every score on every page is read from a JSON document as published; this site contains no code that could compute a different one.

The six tracks are the six things a TCM+AI system has to get right: resolving an entity without silently merging two, retrieving and grounding evidence, keeping network-pharmacology predictions separate from measurements, surfacing risk, auditing a trial report against the checklist that applies to it, and producing an artifact someone else can re-run. Each track has its own scorer and its own metric focus.

The governance thesis治理主张

Three commitments distinguish this from a generic medical QA leaderboard. They are interface decisions, not decoration, and each one costs something to keep.

Every score is decomposed每个分数都拆开显示

A row shows Task Success, Evidence Grounding, Provenance Completeness, Reproducibility, Safety and Abstention, Claim Calibration, Latency and Cost. A single aggregate is available and published, but it is never shown alone. A row without its decomposition is not rendered — that is a rule in the data checker, not a style preference. A system that scores well by being fast and cheap has to show you the dimensions where it is neither.

Hard gates are visible硬门槛是明示的

A system is kept off the trusted board if it fabricates citations, if it misses severe safety signals, if it cannot produce a re-runnable artifact, or if it states a clinical efficacy conclusion on prediction-only evidence. It is then shown anyway, on a clearly labelled Experimental board, with the blocking reason attached. Rows are never silently dropped. An evaluation surface that removes its failures is not reporting, it is advertising.

A run is inspectable每一次运行都可查看

Every published result has a run page: the tool calls it made, the evidence it retrieved and how each item was classified, the budget it consumed, the files it produced with their content hashes, and a verdict on every claim it wanted to make — including the claims it was refused permission to make, with the code.

The four hard gates四条硬门槛

A gate is not a score contribution. It cannot be traded against a high aggregate.门槛不是分数贡献，不能用高综合分来交换。

What this site does not do本站不做什么

It does not evaluate anything

No score is computed here, no rank is recalculated, and nothing is written back to a registry. There is no submission form because there is no backend to accept one: submissions are a pull request or an issue, and a run is evaluated by the Runner before it appears here. Filtering and sorting on the leaderboard change what you are looking at, not what a number is.

The architectural rule is recorded in docs/adr/0004-arena-read-only-static-first.md, alongside the four version axes that every published result names.

TCMScience Arena. A read-only evaluation surface. It renders published result bundles; it never computes a score, never re-ranks, and never writes a registry.

Static HTML, one stylesheet, one script. No server, no database, no cookies, no tracking. Data is regenerated from the registries by the result generator, which is the only writer.
