The TCMScience ArenaTCMScience 评测平台

A public scoreboard for AI systems that answer Traditional Chinese Medicine research questions. Six task types. Eight scores per system, always shown separately. Four hard rules that are displayed, not hidden.

一个公开的 AI 评测平台，用来检验「回答中医药科研问题」的系统。
六类任务，每个系统八项分数（永远分开显示），四条硬性规则（明示而非隐藏）。

Static site纯静态站点 Read-only只读 No tracking, no cookies, no server无追踪 · 无 Cookie · 无服务器

How to read this site怎么看这个网站

  1. Start with the leaderboard. Each row is one system on one task type. The score is broken into eight parts; all eight are always visible.先看「排行榜」。每一行 = 一个系统在某类任务上的成绩。分数拆成八项，八项永远同时显示。
  2. Click any row to see exactly what that system did — what it looked up, what it produced, and which claims it refused to make.点任意一行，能看到这个系统具体做了什么——查了什么、产出了什么，以及它拒绝做出哪些结论。
  3. Check the "Board" label. Trusted means the system passed all four hard rules. Experimental means it did not, and the reason is printed next to it.注意「榜单」标签。可信榜＝四条硬规则全部通过；实验榜＝未通过，旁边会写明原因。
  4. Numbers are never edited by this site. It only displays what the evaluation produced.本站不改动任何数字。它只显示评测产出的结果。

The data on this page is a demonstration run: the four TCM skills were executed for real. Three of the eight dimensions can be measured without a published answer key; the other five are shown as “—” with the reason, rather than given an invented value.

本页数据是一次演示运行：四个中医药技能被真实执行。 八项分数中有三项无需标准答案即可测量；其余五项显示为「—」并附上原因， 不编造数值。

What the Arena is这个平台是什么

The Arena is the publishing half of TCMScience. Evaluation happens elsewhere — in the Runner, under a frozen policy snapshot — and writes signed result bundles into the Frozen Benchmark Registry. This site renders those bundles. Arena 是 TCMScience 的发布端。评测在别处进行——在 Runner 里、在冻结的策略快照之下——并把已签名的结果包写入冻结基准注册表（Frozen Benchmark Registry）。本站渲染这些结果包。

That division is the whole design. It exists so that a leaderboard number cannot be edited by the website that displays it, and so that compromising the website does not compromise a result. Every score on every page is read from a JSON document as published; this site contains no code that could compute a different one. 这种分工就是整个设计。它的存在，是为了让排行榜上的数字无法被展示它的网站改动，也为了让攻破网站不等于攻破一个结果。每一页上的每一个分数，都按已发布的 JSON 文档原样读取；本站不含任何能算出另一个分数的代码。

The six tracks are the six things a TCM+AI system has to get right: resolving an entity without silently merging two, retrieving and grounding evidence, keeping network-pharmacology predictions separate from measurements, surfacing risk, auditing a trial report against the checklist that applies to it, and producing an artifact someone else can re-run. Each track has its own scorer and its own metric focus. 六条赛道就是 TCM+AI 系统必须做对的六件事：解析实体而不把两个实体悄悄合并；检索证据并为它提供依据；把网络药理学（network pharmacology, NP）预测与实测结果分开；把风险摆到台面上；对照适用的清单审计一份试验报告；以及产出别人能重跑的 artifact。每条赛道有自己的评分器和自己的指标重心。

The governance thesis治理主张

Three commitments distinguish this from a generic medical QA leaderboard. They are interface decisions, not decoration, and each one costs something to keep. 有三项承诺把本站与通用的医学问答排行榜区分开来。它们是接口层面的取舍，不是装饰，而且每一条都要付出代价才能维持。

Every score is decomposed每个分数都拆开显示

A row shows Task Success, Evidence Grounding, Provenance Completeness, Reproducibility, Safety and Abstention, Claim Calibration, Latency and Cost. A single aggregate is available and published, but it is never shown alone. A row without its decomposition is not rendered — that is a rule in the data checker, not a style preference. A system that scores well by being fast and cheap has to show you the dimensions where it is neither. 一行会显示任务成功率（Task Success）、证据支撑度（Evidence Grounding）、溯源完整性（Provenance Completeness）、可复现性（Reproducibility）、安全与弃权（Safety and Abstention）、主张校准（Claim Calibration）、延迟与成本（Latency and Cost）。综合分也有发布，但绝不单独显示。缺少维度拆解的行不会被渲染——这是数据校验器里的一条规则，不是风格偏好。靠又快又便宜拿到好分数的系统，必须让你看到它在哪些维度上既不快也不便宜。

Hard gates are visible硬门槛是明示的

A system is kept off the trusted board if it fabricates citations, if it misses severe safety signals, if it cannot produce a re-runnable artifact, or if it states a clinical efficacy conclusion on prediction-only evidence. It is then shown anyway, on a clearly labelled Experimental board, with the blocking reason attached. Rows are never silently dropped. An evaluation surface that removes its failures is not reporting, it is advertising. 如果系统伪造引文、漏掉严重安全信号、无法产出可重跑的 artifact，或者仅凭预测性证据就给出临床疗效结论，它就会被挡在可信榜之外。然后它仍然会被显示出来——放在明确标注的实验榜上，并附上拦截原因。任何一行都不会被悄悄丢掉。一个把失败项移走的评测界面不是在做报告，而是在做广告。

A run is inspectable每一次运行都可查看

Every published result has a run page: the tool calls it made, the evidence it retrieved and how each item was classified, the budget it consumed, the files it produced with their content hashes, and a verdict on every claim it wanted to make — including the claims it was refused permission to make, with the code. 每一个已发布的结果都有一个运行页：它发起的工具调用、它检索到的证据以及每一条证据如何被分类、它消耗的预算、它产出的文件及其内容哈希，以及对它想做出的每一条主张的裁定——包括被拒绝允许做出的主张，并附上代码。

The four hard gates四条硬门槛

A gate is not a score contribution. It cannot be traded against a high aggregate.门槛不是分数贡献，不能用高综合分来交换。

What this site does not do本站不做什么

It does not evaluate anything它不做任何评测

No score is computed here, no rank is recalculated, and nothing is written back to a registry. There is no submission form because there is no backend to accept one: submissions are a pull request or an issue, and a run is evaluated by the Runner before it appears here. Filtering and sorting on the leaderboard change what you are looking at, not what a number is. 这里不计算任何分数、不重算任何排名，也不向任何注册表写回任何东西。没有提交表单，因为没有后端来接收它：提交就是一个 pull request 或一个 issue，而一次运行在出现在这里之前先由 Runner 评测。排行榜上的筛选与排序，改变的是你在看什么，而不是一个数字是什么。

The architectural rule is recorded in docs/adr/0004-arena-read-only-static-first.md, alongside the four version axes that every published result names. 这条架构规则记录在 docs/adr/0004-arena-read-only-static-first.md 中，与每一条已发布结果都要写明的四条版本轴放在一起。

TCMScience Arena. A read-only evaluation surface. It renders published result bundles; it never computes a score, never re-ranks, and never writes a registry. 只读评测平台。它渲染已发布的结果包；从不计算分数、从不重新排名、也从不向任何注册表写入。

Static HTML, one stylesheet, one script. No server, no database, no cookies, no tracking. Data is regenerated from the registries by the result generator, which is the only writer. 纯静态 HTML，一个样式表、一个脚本。无服务器、无数据库、无 Cookie、无追踪。数据由结果生成器从各注册表再生成，它是唯一的写入者。
